모바일 UI — 어느 영역이 가장 어색한가요?

개선이 필요한 곳을 모두 선택해 주세요 (복수 선택 가능)

A

상단 헤더 / 탭바

앱 이름, 탭 전환 버튼, 계정 정보 영역 — 전체 레이아웃과 밀도

B

로그인 화면

Google 로그인 버튼, 배경, 앱 소개 — 첫인상이 촌스럽거나 밋밋한 느낌

C

출석 카드 그리드

이름 카드 터치 크기, 출석/결석 색상, 선택 피드백

D

사이드바 / 히스토리 패널

보고서 목록, 저장 버튼, 패널 배치 — 모바일에서 공간 낭비 느낌

E

보고서 입력 폼

날짜/숫자 입력, 레이블, 섹션 구분 — 정보 밀도가 너무 높거나 낮음

F

전체적인 느낌

색상, 여백, 폰트 — 특정 화면보다는 전반적인 세련미 부족
