# 탭 기반 보고서 UI 설계

## Goal

보고서 입력 폼을 부서별 탭 구조로 재편해 스크롤 없이 각 부서에 바로 접근할 수 있게 한다. 데스크톱과 모바일 모두 동일한 탭 구조를 사용한다.

## Architecture

`ReportForm` 컴포넌트를 `TabbedReportForm`으로 교체한다. 탭 상태(`activeTab`)를 컴포넌트 내부에서 관리하며, 각 탭은 기존 에디터 컴포넌트를 그대로 재사용한다. 레이아웃에서 우측 미리보기 패널을 제거하고, 사이드바 너비를 줄인다.

## Tech Stack

React 19, TypeScript, CSS (기존 스타일 확장)

---

## 모드 전환 (변경 없음)

상단 세그먼트 컨트롤: **보고서 | 뷰어 | 명단관리**  
뷰어·명단관리 모드는 현행 그대로 유지.

## 탭 구조

보고서 모드 내부에 6개 탭:

| 탭 키 | 라벨 | 내용 |
|---|---|---|
| `info` | 기본정보 | 제목·보고일·보고자 입력 필드 + 리포트 미리보기 |
| `elementary` | 유초등부 | 출석카드 에디터 (인원추가·전원출석·전원결석·카드) |
| `middleHigh` | 중고등부 | 위와 동일 |
| `youngAdult` | 청년부 | 위와 동일 |
| `adult` | 교구 | 구역별 출석 에디터 + 문자 발송 버튼 |
| `prayer` | 기도·광고 | 기도제목·광고 textarea |

기본 활성 탭: `info`

## 컴포넌트 설계

### TabbedReportForm

```
TabbedReportForm
├── TabBar (탭 버튼 목록)
├── InfoTab (기본정보 + 미리보기)
├── DepartmentTab (유초등부·중고등부·청년부 공용)
├── AdultTab (교구 — ZonedDepartmentAttendanceEditor 래핑)
└── PrayerTab (기도·광고)
```

- `activeTab: TabKey` 상태 내부 관리
- 탭 전환 시 미저장 내용 손실 없음 (report 상태는 상위 App.tsx에 있음)
- 각 탭은 `display: none` / `display: block`으로 마운트 유지 (재렌더 방지)

### 파일 변경

## 레이아웃

### 데스크톱

```
┌──────────┬──────────────────────────────────────────┐
│ 사이드바  │ [기본정보][유초등부][중고등부][청년부][교구][기도·광고] │
│ (200px)  ├──────────────────────────────────────────┤
│ 계정     │                                          │
│ 새보고서  │         현재 탭 내용                     │
│ 저장     │                                          │
│ 내보내기  │                                          │
└──────────┴──────────────────────────────────────────┘
```

- 사이드바: 현재 너비에서 200px로 축소
- 우측 미리보기 패널: 제거
- 탭 콘텐츠 영역: 나머지 전체 너비 사용

### 모바일

```
┌─────────────────────────────┐
│  보고서 | 뷰어 | 명단관리    │
├─────────────────────────────┤
│ [기본정보][유초등부]... scroll│
├─────────────────────────────┤
│       탭 콘텐츠             │
└─────────────────────────────┘
```

- 탭 바: 가로 스크롤 가능 (`overflow-x: auto`)
- 탭 버튼: 고정 너비 또는 균등 분배

## 기본정보 탭 상세

- 제목, 보고일, 보고자 입력 (현행 유지)
- 하단에 `ReportPreview` 컴포넌트 배치 (현행 우측 패널에서 이동)
- 미리보기는 보고서 전체를 렌더링

## CSS 변경 범위

- `.sidebar`: `width: 200px` (기존보다 좁게)
- `.report-preview-panel`: 제거
- `.tab-bar`, `.tab-btn`, `.tab-btn.active`, `.tab-content`: 신규 추가
